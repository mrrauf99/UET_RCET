# Focus Audio recordings

`focus.wav` and `deeper.wav` are approximately 60-second captures of the live Focus Audio output on https://www.northampton.ac.uk/, recorded on 6 October 2026 at the user's request.

The Recite Me toolbar synthesizes these tracks using Web Audio oscillators, chord sequences and gain envelopes. It does not provide downloadable song files. These WAV files capture the toolbar's actual output at its current player volume; they are not the previous substitute music. Focus includes randomized variations, so each live performance differs.

Format: uncompressed 16-bit PCM WAV. The app plays these local recordings with looping enabled.

This provenance note does not assert an open-source or Creative Commons license for the recordings.
